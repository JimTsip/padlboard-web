# padlboard-web

The coming-soon landing page for [padlboard.ai](https://padlboard.ai) — a padel companion for Apple Watch, iPhone, and web.

Static site (no build step), deployed via GitHub Pages. There is no form on the page any more — the app is out, so the hero links to the App Store and `hello@padlboard.ai`. The old waitlist form posted to Supabase; the backend now lives on Cloudflare (`padlboard-api`, see the app repo's `backend/`).

This will grow into the full Next.js web app described in the main repo's `docs/padlboard-master-plan.md` once that track starts; for now it's just the placeholder.
